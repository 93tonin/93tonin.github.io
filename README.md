# 📚 93tonin | Estante de Livros Recomendados

Bem-vindo ao repositório oficial da minha estante digital! Este projeto reúne uma curadoria pessoal de livros essenciais sobre
filosofia, comportamento humano, história, política e literatura clássica que moldaram minha visão de mundo.

🔗Acesse o site ao vivo: https://93tonin.github.io

---

#✨ Sobre o Projeto
A página foi desenvolvida para oferecer uma navegação rápida, responsiva e visualmente imersiva, utilizando estética *Glassmorphism* (efeito de vidro fosco translúcido) sobre um plano de fundo temático.

* Design Responsivo: Adaptado tanto para telas de computador quanto para leitura confortável em dispositivos móveis.
* Curadoria Direta: Resumos objetivos e links diretos para aquisição das obras recomendadas.
* Conexões: Acesso rápido à minha playlist no Spotify e demais redes sociais.

---

#🛠️ Estrutura dos Arquivos
* `index.html`: Estrutura principal da página, estilos (CSS) e catálogo dos livros.
* `fundo.jpg`: Imagem de plano de fundo utilizada na interface.
